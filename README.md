# 水墨古风状态栏

一个具有中国传统水墨画风格的游戏状态栏界面，采用书卷/竹简的视觉设计，展现古典雅致的美感。

## 功能特性

### 🎨 视觉设计
- **水墨古风**：采用传统水墨画色彩搭配
- **书卷形态**：模拟古代书卷的展开效果
- **动态背景**：飘逸的水墨点缀动画
- **渐变质感**：仿古纸张的质感效果

### 📊 状态显示
- **人物状态**：姓名、气血、内力、境界
- **名声系统**：阵营、声望、称号
- **行囊管理**：盘缠、兵刃、杂物清单
- **任务追踪**：主线任务、支线任务

### ⚡ 交互功能
- **动态进度条**：气血和内力的可视化显示
- **悬停效果**：鼠标悬停时的优雅动画
- **点击反馈**：点击状态项的缩放动画
- **响应式设计**：适配不同屏幕尺寸

## 使用方法

### 基本使用
1. 直接在浏览器中打开 `index.html`
2. 状态栏会自动加载并显示默认数据

### 数据更新
通过JavaScript API更新状态栏数据：

```javascript
// 更新单个数据
window.statusBarManager.updateData('姓名', '新角色名');
window.statusBarManager.updateData('当前气血', 950);

// 批量更新数据
window.statusBarManager.updateMultipleData({
    '姓名': '张无忌',
    '境界': '金丹期',
    '当前气血': 1200,
    '最大气血': 1500,
    '称号': '明教教主'
});
```

### 支持的数据字段

| 字段名 | 类型 | 说明 |
|--------|------|------|
| 姓名 | String | 角色姓名 |
| 当前气血 | Number | 当前生命值 |
| 最大气血 | Number | 最大生命值 |
| 当前内力 | Number | 当前法力值 |
| 最大内力 | Number | 最大法力值 |
| 境界 | String | 修炼境界 |
| 阵营 | String | 所属阵营 |
| 声望等级 | String | 声望等级 |
| 称号 | String | 角色称号 |
| 盘缠 | String | 金钱数量 |
| 兵刃 | String | 装备武器 |
| 杂物列表 | Array | 物品清单 |
| 主线任务标题 | String | 主要任务名称 |
| 主线任务描述 | String | 任务详细描述 |
| 支线任务 | String | 支线任务名称 |

## 样式定制

### 颜色主题
可以通过修改CSS变量来调整颜色主题：

```css
:root {
    --primary-bg: #f5f1e8;      /* 主背景色 */
    --secondary-bg: #e8dcc0;    /* 次要背景色 */
    --text-primary: #3c2415;    /* 主要文字色 */
    --text-secondary: #5d4e37;  /* 次要文字色 */
    --accent-color: #8b7355;    /* 强调色 */
}
```

### 字体设置
项目使用了Google Fonts的中文字体：
- **Ma Shan Zheng**：标题字体
- **ZCOOL XiaoWei**：正文字体
